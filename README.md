# Project
The Smart Weather Forecasting and Alert System is a Java-based application designed to provide weather forecasts and send timely alerts about changing weather conditions. The system retrieves and processes weather data to display information such as temperature, humidity, wind speed, and weather conditions. It can also generate alerts for severe weather conditions, helping users stay informed and take necessary precautions.

This project demonstrates the use of Java programming, object-oriented programming concepts, API integration, data processing, and alert notification systems.

Key Features:

- Real-time weather forecasting
- Temperature and humidity monitoring
- Weather condition updates
- Severe weather alerts and notifications
- User-friendly interface
- API-based weather data integration

Technologies Used:

- Java
- Object-Oriented Programming (OOP)
- Weather API
- Java Swing / JavaFX (if applicable)
- MySQL (if applicable)
